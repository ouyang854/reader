# 静态文献阅读器

这个版本不需要运行 `server.py`，也不扫描电脑文件夹。

## 使用方式

直接打开：

```text
index.html
```

或把整个 `literature_reader_static` 文件夹上传到 GitHub Pages、Cloudflare Pages、Netlify 等静态网页托管服务。

## 功能

- 手动导入 PDF。
- 手动导入对应的 `.md` / `.txt` 译文。
- 如果同时选择 PDF 和译文，会尝试按文件名自动匹配。
- 原文 PDF 和译文并排显示。
- 支持已读标记、搜索、筛选、批注。
- 按住 `Alt` 滚动鼠标滚轮时，原文和译文会同步滚动。
- 数据保存在浏览器 IndexedDB 中。
- 可以导出备份 JSON，也可以导入备份 JSON。

## 注意

- 纯静态网页不能自动读取某个电脑文件夹，这是浏览器安全限制。
- PDF 渲染使用 PDF.js CDN，因此首次打开需要网络。
- 数据默认只保存在当前浏览器。换电脑前请先导出备份。
